# 发票数据规范与业务默认配置

本工具的发票 JSON 格式支持批量导入多个发票对象。每个发票对象包含购买方基本信息和商品明细列表。

## 1. 核心业务默认配置 (自行车业务)

在处理自行车、电动车及其零配件业务时，必须遵循以下默认业务规则：

| 业务分类 | 字段 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **发票基本信息** | `invoiceType` | `"普通发票"` | 默认开具电子普通发票 |
| | `isTaxIncluded` | `"是"` | 金额字段默认为**含税金额** |
| | `isNaturalPerson` | `""` | 默认非自然人 (对应界面上的 "否") |
| **明细行信息** | `taxRate` | `0.01` | **核心规则**：税率统一按 **1%** (0.01) |
| | `unit` | `"辆"` 或 `"个"` | 根据具体商品确定 |

## 2. 推荐税收分类编码 (自行车类)

| 商品名称 | 推荐编码 | 说明 |
| :--- | :--- | :--- |
| 两轮脚踏自行车 | `1090314010000000000` | 最常用的整车编码 |
| 三轮脚踏自行车 | `1090314020000000000` | |
| 脚踏自行车零件 | `1090314040000000000` | 零配件、修补件通用 |

## 3. JSON 数据结构示例 (复用标准导出格式)

```json
[
  {
    "serialNo": "INV20260603001",
    "invoiceType": "普通发票",
    "specialBusiness": "",
    "isTaxIncluded": "是",
    "buyerName": "上海某某自行车贸易有限公司",
    "buyerTaxId": "91310115MA1K3XXXXX",
    "isNaturalPerson": "",
    "buyerAddress": "上海市浦东新区某某路123号",
    "buyerPhone": "021-12345678",
    "buyerBankName": "中国建设银行上海分行",
    "buyerBankAccount": "6222000000000000000",
    "remark": "2026年6月采购款",
    "buyerEmail": "finance@example.com",
    "items": [
      {
        "name": "山地自行车",
        "code": "1090314010000000000",
        "spec": "27.5寸",
        "unit": "辆",
        "qty": 10,
        "price": 800,
        "amount": 8000,
        "taxRate": 0.01
      }
    ]
  }
]
```

## 4. 字段详细定义

- `serialNo`: 唯一流水号，建议格式 `INV + 时间戳`。
- `isNaturalPerson`: 若为 `"是"`，则必须提供 `buyerIdType` 和 `buyerIdNo`。
- `items.code`: 必须是有效的 19 位税收分类编码，可通过 CLI 搜索验证。
- `items.amount`: 应满足 `qty * price = amount` (含税)。
